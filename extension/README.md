# CHATBOT Chrome 擴充功能（第一版）

## 安裝
1. 將 ZIP 解壓縮。
2. Chrome 開啟 `chrome://extensions`，啟用「開發人員模式」。
3. 點「載入未封裝項目」，選取包含 `manifest.json` 的資料夾。
4. 點 CHATBOT 圖示，輸入一次性配對碼。
5. 開啟目標網站，按「啟用此網站」並同意網站權限。
6. 依序點「對方訊息」、「輸入框」，回網頁點選目標元素；Esc 取消。
7. 新訊息出現後，網頁右下角會顯示 AI 建議，選「填入」自行確認送出。

## 安全
- 沒有擅自發送訊息功能。WooTalk 有對未經許可自動化的限制。
- Gemini / Supabase service_role 金鑰只在雲端，不會放入 Chrome。
- 只有明確授權的網域會註冊內容腳本。
- 只讀取使用者選擇的訊息元素，不讀取整頁內容。
- 每個頁面工作階段隔離；新配對對話可按「新對話／清除記憶」。
- 封閉 Shadow DOM、Canvas、iframe、特殊輸入框等需額外適配。
- LINE Bot 完全獨立，不因安裝擴充功能改動 Webhook。
- 使用者應自行確認已取得聊天參與者的資訊使用同意。

## 程式模組
`background.js`：Supabase API、裝置憑證，保留於可信任擴充功能上下文。
`content.js`：接收新訊息、點選欄位與顯示回覆。
`popup.js`：配對、逐站啟用、選取頁面元素和測試。
